# AMIRU AI STUDIOS — Website files

## Publish free using GitHub Pages
1. Sign in to GitHub as `Ecosystemexpansioneem26`.
2. Create a **Public** repository named exactly `Ecosystemexpansioneem26.github.io`.
3. Upload every file in this folder to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. When deployment completes, visit `https://Ecosystemexpansioneem26.github.io/`.

## Add videos
Edit `videos.json` and add an object like:
```json
{
  "title": "My new AI advertisement",
  "category": "Luxury Products",
  "description": "A cinematic product advertisement.",
  "video": "https://www.youtube.com/embed/VIDEO_ID",
  "thumbnail": "https://example.com/thumbnail.jpg"
}
```
Allowed category names: `Real Estate`, `Luxury Products`, `Fashion`, `Automotive`, `UGC & Social Ads`, `Cinematic`.

## Video hosting limitation
GitHub Pages hosts the website, not a video-upload dashboard. Large MP4 files should not be stored in the GitHub repository. This gallery plays videos embedded from a video host or from a direct MP4 URL. A genuinely unlimited, completely free video-hosting service is not something I can promise. The sample gallery cards are placeholders until you add your actual video links.
